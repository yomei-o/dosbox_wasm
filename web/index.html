使いかた

起動すると C:\JWCAD\JW_CADV.EXE が立ち上がります。 図面は C: ドライブ（ブラウザの IndexedDB）に保存され、リロードしても残ります。 上の一覧から 取り出す で .JWC を手元にダウンロードでき、 ファイルを入れる で手元の図面を持ち込めます。

マウス

マウスは掴みません。カーソルはそのままポインタに追従するので、 画面と上の入力欄を自由に行き来できます。 右クリックもそのまま JW_CAD に渡ります（ブラウザのメニューは出ません）。

キー操作

Ctrl+F10マウスの掴み／解放
AltJW_CAD の GRPH
EndJW_CAD の HELP
HomeJW_CAD の HOME/CLR

日本語入力 — 文字を書き込む手順

  1. 右メニューの 文 字（キーは A）を選ぶ
  2. 図面上の書きたい位置をクリックする
  3. 画面の上に 文字列入力 と緑のカーソルが出る
  4. Ctrl+Space を押す。画面の下に入力欄が開くので、 いつもの IME で日本語を打って Enter
  5. 入力欄が閉じてキー操作が JW_CAD に戻る。文字列が 文字列入力 に 入っているので、Enter で確定して置く位置をクリック

入力欄は画面の上に重ねて出るので、目もマウスも動かさずに済みます。 Esc で何も送らずに閉じられます。

かな漢字変換はブラウザの IME が行います。DOS 側の FEP は要りません。 確定した文字列が Shift_JIS に変換され、JW_CAD のキーボードバッファへ直接送られます。 JW_CAD の画面に直接タイプしても日本語にはなりません（DOS 側に FEP がないため）。

DOSBox-X はもともと、ホストの IME で打った文字をゲストのコードページに変換して キーボードバッファへ積む経路を持っています（FEP が変換確定文字を渡すのと同じ仕組み）。 ただしその処理は Windows / X11 / macOS 用の #if の中にあり、 Emscripten ビルドでは丸ごと消えています。そこで最後の一段だけを dosbox_x_type_bytes として外に出し、ページから呼んでいます。

図面を PNG / SVG / PDF で取り出す

JW_CAD のプロッタ出力を受け取って PNG / SVG / PDF に変換します。線・円弧・点のほか、SVG と PDF では 文字は文字のまま入るので、検索もコピーもできます。 PDF の日本語は標準の CJK エンコーディングを使うので、フォントを埋め込まずに済みます。PNG は用紙の長辺のピクセル数を選べます（A1 なら 2400px でおよそ 72dpi）。 大きくすると読みやすくなりますが、書き出しに時間がかかります。

JW_CAD 側の手順です。いちばんつまずくところを先に書きます。 上部のバーに (L) (R) と書かれている項目は、 バーではなく作図領域（黒いところ）を左／右クリックして選びます。 数字キーでは選べません。

プリンタポート経由（おすすめ）

ファイル名を聞かれないぶん手数が少なくて済みます。

  1. 入出力（左メニュー、q）→ 2 プロッタ
  2. 上部に 2)プリンタポート出力(R) と出るので、 作図領域を右クリック
  3. 一覧から WASM.JWP を選び、もう一度クリックして確定
  4. 設定画面（1)確定(L)）→ 作図領域を左クリック
  5. 作図開始（1) 実行(L)）→ 作図領域を左クリック
  6. 上の PNG / SVG / PDF を押す

出力は C:\PLOT.PRN に固定です。下のファイル一覧に現れていれば 成功しています。

ファイル出力

出力ごとに名前を付けられるので、複数の図面を区別したいときはこちら。

  1. 入出力（q）→ 2 プロッタ
  2. 3 ファイル出力
  3. 一覧から WASM.JWP を選び、もう一度クリックして確定
  4. 「出力ファイル名 ?」に名前を入れて Enter
  5. 設定画面 → 作図領域を左クリック（確定）
  6. 作図開始 → 作図領域を左クリック（実行）
  7. 上の PNG / SVG / PDF を押す

どちらで出しても、変換ボタンは C: にあるいちばん新しい プロッタ出力を拾います。うまくいかないときは、変換後の状態表示に 出る「出力の中身」を見てください。M 移動 / D 線 / C 円弧 / A 半角 / K 全角 の件数です。 ここが空なら、手順のどこかで出力されていません。

WASM.JWP はこのページが用意しているプロッタ設定ファイルです。 実在のプロッタ用ではなく、変換しやすい形で書き出させるためのものです。

これは何か

DOSBox-X を WebAssembly に ビルドし、DOS/V エミュレーション（dosv=jp）を有効にしたものです。 JW_CAD の DOS/V 版は VGA 640×480 のグラフィックス画面に直接描画し、 漢字は DOS/V のフォント API 経由で取得します。DOSBox-X は内蔵フォントで これを賄うので、実機の DOS/V は要りません。
